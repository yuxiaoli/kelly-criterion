# Kelly Criterion Result Interpretation Guide

This document explains how to interpret the results generated by the Kelly Criterion calculation tool and applies them to a practical investment scenario.

## 1. Project Overview

This tool calculates the **optimal capital allocation** for a portfolio of securities to maximize long-term geometric growth. It uses the **Kelly Criterion** formula, assuming that historical performance (mean return and covariance) is a reasonable estimator for future performance.

## 2. Inputs and Outputs

### Inputs
*   **Risk-free Rate**: Annualized risk-free rate (e.g., 0.04 for 4%).
*   **Timeframe**: Start and end dates for historical data analysis.
*   **Securities**: List of ticker symbols (e.g., IBB, SPY, VDE).

### Outputs
The program outputs the **Leverage ($f_i$)** for each security.

*   **Positive Leverage ($f > 0$)**: Represents a **Long** position. You should buy this security.
*   **Negative Leverage ($f < 0$)**: Represents a **Short** position. You should borrow and sell this security.

## 3. Practical Application Example

**Scenario**: You have an account equity of **$1,000,000**.

**Sample Output**:
```text
Leverages per security:
  IBB: 3.61
  SPY: -2.73
  VDE: 1.04
Sum leverage: 1.92
```

### Execution Strategy

To follow this recommendation, you would allocate capital as follows:

| Security | Leverage | Action | Transaction Value |
| :--- | :--- | :--- | :--- |
| **IBB** | 3.61 | **Buy (Long)** | $1,000,000 $\times$ 3.61 = **$3,610,000** |
| **SPY** | -2.73 | **Sell (Short)** | $1,000,000 $\times$ 2.73 = **$2,730,000** |
| **VDE** | 1.04 | **Buy (Long)** | $1,000,000 $\times$ 1.04 = **$1,040,000** |

### Portfolio Analysis

*   **Total Long Position**: $3.61m + $1.04m = **$4.65 million**
*   **Total Short Position**: **$2.73 million**
*   **Net Exposure**: $4.65m - $2.73m = **$1.92 million** (1.92x Net Leverage)
*   **Gross Exposure**: $4.65m + $2.73m = **$7.38 million** (7.38x Gross Leverage)

## 4. Critical Risk Warnings

While the Kelly Criterion defines the mathematically optimal bet size for maximizing growth, the "Full Kelly" result is often **too risky for practical trading**:

1.  **Margin Constraints**: A Gross Leverage of **7.38x** is extremely high. Most brokers (e.g., under Reg T) limit overnight leverage to approximately **2x**. Attempting the allocation above would likely result in an immediate **Margin Call** and forced liquidation.
2.  **Volatility**: Full Kelly strategies can experience massive drawdowns (e.g., >50% loss of capital).
3.  **Model Risk**: The calculation assumes future returns distribution will match the past exactly. If market conditions change, the "optimal" leverage becomes incorrect.

### Recommendation: "Half Kelly"

Professional practitioners often use a **Fractional Kelly** strategy (e.g., **Half Kelly**) to reduce volatility and model risk while still aiming for growth.

Applying **Half Kelly** to the example above:
*   **IBB**: Buy $1,805,000 (1.8x)
*   **SPY**: Short $1,365,000 (1.36x)
*   **VDE**: Buy $520,000 (0.52x)
*   **Total Gross Leverage**: ~3.7x (Still high, but more manageable than 7.4x)
